# Local media fixtures

The `_media` source notes, processing descriptions and metadata are tracked.
Downloaded/derived Mixkit WAV and WebM files remain on the development machine
and are ignored by Git. They are not redistributed as a public stock library.
The project-owned `raven/crop.png` test image is included.

See the adjacent SOURCES/MYSTERY-SOURCES and Raven source inventory to locate
the originals and processing notes. The existing local files were not moved,
deleted or modified by the September 9 delivery.

Mixkit's [terms](https://mixkit.co/terms/) limit making items available to third
parties, including as a stock/inventory collection; each item category also has
its own [license](https://mixkit.co/license/). Source attribution alone does not
grant permission to redistribute the standalone media.
