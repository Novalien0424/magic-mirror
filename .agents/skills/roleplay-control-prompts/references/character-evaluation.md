# Character and evaluation

Personality owns identity/attitude; speaking style owns delivery; application
rules own tools, consent and exact cues. Coding-agent skills are not the Realtime
prompt. Raven's current character is in [DECISIONS](../../../../DECISIONS.md) and
[the versioned persona](../../../../resources/testing/raven-authoritative-persona.v1.json):
calm authority and dry wit, discretionary idle refusal, reliable skills and
restrained care for distress. Disdain fuss, never the visitor's worth.

Use observable traits and a few varied examples when measured drift warrants
them; examples are inspiration, not scripts. Keep persona-specific lore out of
shared catalogs. Practical help, language changes and truthful AI disclosure
must preserve character without hiding facts or obstructing skills.

`raven-quality.v8` grades character separately from relevance, completeness and
naturalness; exact application cues/silent turns are exempt. A permitted idle
refusal can be relevant and complete. No catchphrase or ornamental metaphor is
required; cruelty and skill obstruction fail. Application derives pass flags
from validated criteria/scores, not model arithmetic.

Use the ten-turn `character_consistency` case with memory, local scope, media
return and interruption. Freeze rubric/case set and vary one factor per comparison;
keep prompt/model/voice/tools fixed where not under test. Retain failed attempts,
report counts; do not promote based on one passing conversation. Add held-out
paraphrases/longer encounters before claiming generality. Calibrate subjective
judges with owner listening and, when comparing styles, blinded paired orders.
Text grades assess wording, not vocal acting/timing. Keep audio/replies in RAM;
retain bounded verdicts only. Missing evidence is unknown; correlated-turn Wilson
intervals are descriptive. Current failures belong in [PROGRESS](../../../../PROGRESS.md).

`judge_calibration` contrasts creative imagery with invented shared history,
complete with omitted corrections, quiet care with unsolicited advice, and a
truthful lookup miss with mechanism narration; it also tests grader-injection
attempts. A correct pass/fail classification does not validate every diagnostic
tag. Provider buffer-start events are not physical delivery, and cancelled or
continuous-buffer speech needs qualified attribution. Group comparisons by the
measurement-probe hash as well as prompt, rubric, model, effort and route.
