# Focused avatar survey

Answer only questions that affect the requested authoring outcome. Identify available source (portrait/PSD/partial layers/CMO/runtime), actual Photopea/Cubism mode and tools, current importer/IDs/Core compatibility, and concrete art bottlenecks. Investigate licenses/budget only when relevant.

Distinguish current code, official documentation, observed tool behavior, recommendations and unknowns. Use existing source and the chosen Photopea/Cubism route: complete PSD→rig, image→separation, CMO→resume or runtime→validation as appropriate. Side-view or nonhuman art can need manual hierarchy; that does not make a PNG impossible to rig.

Use current project contracts, tool documentation/UI and official sources. Do not inspect secrets. A callable API is not evidence of successful canvas editing. Suggest alternatives only for a concrete tool/version/mode/quality blocker; do not silently switch to 3D, video avatars or paid cloud services.

Use the [learning map](cubism-learning-map.md) only for missing knowledge. Check parameter IDs, numbers and menus against documentation/current UI rather than trusting auto captions. Record whether a source was a page body, transcript, frame sample or index; research is not authoring acceptance. A request for all relevant teaching material needs explicit coverage, not a claim to have watched the entire internet. Retain notes and timestamps, not repackaged third-party transcripts.
